# Phase 6 – Monitoring com Prometheus e Grafana

## Introdução

O Analytics Service e o Location Service são responsáveis por agregar dados de múltiplos microserviços internos via gRPC. Com vários serviços em execução simultânea, não existe atualmente qualquer software nem maneira de os observar, fazendo com que não seja possível determinar a latência de endpoints ou possíveis bottlenecks.
Tendo isso em conta, decidi que para a próxima fase iria implementar monitorização utilizando Prometheus, e para melhor visualizar as suas estatísticas, irei utilizar o Grafana.

## Non-functional requirements

- Monitorizar a latência e taxa de pedidos por endpoint REST
- Registar a taxa de erros gRPC nas chamadas internas entre serviços
- Monitorizar o número de réplicas ativas por microserviço e correlacionar com o comportamento do HPA
- Detetar possíveis bottlenecks que estão a afetar a performance

## Technical Architecture

- Os microserviços FastAPI passam a ter um endpoint /metrics que mostra estatísticas sobre os pedidos recebidos
- O Prometheus visita esse endpoint periodicamente, e guarda os seus dados.
- O Grafana lê os dados obtidos pelo Prometheus e apresenta-os em gráficos e dashboards fáceis de visualizar.

## Deployment Plan

### 1. Microservices

- Adicionar `prometheus-fastapi-instrumentator` ao `requirements.txt`
- Adicionar o código necessário ao `main.py` de cada serviço para ativar o endpoint `/metrics`
- Reconstruir as imagens e fazer push para o Artifact Registry

### 2. Deploy do Prometheus e Grafana

- Criar os ficheiros YAML necessários para o Prometheus funcionar no Kubernetes
- Configurar o Prometheus para saber onde encontrar o `/metrics` de cada microserviço
- Criar os YAML para o Grafana

### 3. Configuração do Grafana

- Ligar o Grafana ao Prometheus como fonte de dados
- Criar um dashboard com gráficos de latência, número de pedidos e erros por endpoint

### 4. Testes

- Confirmar que as métricas aparecem corretamente no Grafana
- Fazer pedidos aos endpoints UC04–07, UC19 e UC23 e verificar os gráficos em tempo real
